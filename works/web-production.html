Internal Project

Webサイト・公開中

XORA公式サイト(このサイト)

課題
会社の実績・強み・進め方を体系立てて伝える場所が無く、案件応募のたびに実績を示す手段が限られていた
作ったもの
黒曜石(#03080F)を背景に、金=人間・シアン=AIの配色で「人の想いを、動く仕組みに。」という方針を伝える公式サイト一式(トップ+下層9ページ)
担当範囲
配色・タイポグラフィの設計、Hero部分のCanvas粒子表現、共通ヘッダーのコンポーネント化、レスポンシブ対応、Playwrightによる自動検証まで単独で実施
使用技術
静的HTML / CSS / vanilla JS(外部フレームワーク不使用)。HeroはCanvasで人間側とAI側の手が触れ合う粒子表現を描画。共通ヘッダーは1つのJSファイル(header.js)から全ページへ注入する構成
工夫
粒子アニメーションはprefers-reduced-motion(視差やアニメを抑えたい設定)に対応させ、Canvas初期化に失敗した場合や画像読み込みに失敗した場合は静止画へ自動でフォールバックするようにした
成果・稼働状況
制作中。このページを含むサイト全体がその実例です
