# /会議

3人部屋（ADAM / YHWH / ODIN）。ZEUSは入れない。

1. ZEUS起点なら `営業/判断待ち` の `ODIN指示_*.md` を読む
2. `python3 scripts/odin-meet.py start --topic "…" --source ZEUS指示` または `--source 3人発`
3. ADAM / YHWH / ODIN を別々に走らせ、`四柱会議.md` の3欄だけ書く
4. ODINが報告: `python3 scripts/odin-meet.py report --body "パスとURL"`
5. 関所（銀行・2FA・課金・本人確認）は会長。公開ログインは撃たない
